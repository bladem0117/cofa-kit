# go — 단일 진입점

사용자는 스킬 이름을 외우지 않는다. `$go <하고 싶은 것>`을 치거나 `$go`만 친다. 이 스킬은 **고르고 넘길 뿐** 직접 일하지 않는다.

## 절차
1. **상태 감지** (파일만 읽는다. 명령 실행 없음). 먼저 `docs/board/*.md`(README 제외)를 읽어 다른 창의 `own`·`avoid`·`occupy`를 안다. 이 창의 board 파일이 없으면 AGENTS 3절 형식으로 하나 만든다(세션 시작 = 범위 선점). 그다음 아래 표:

| 관찰 | 현재 단계 |
|---|---|
| `docs/decision-log.md`에 캘리브레이션 엔트리 없음 | 입장 |
| `docs/agreement.md` 없음(실무자 AI가 있거나 과제가 열려 있음) | 발굴·합의 |
| 합의문 있음, `docs/plans/`에 계획 없음 | 지도·계획 |
| 계획 상태 "승인 대기" | 사용자 승인 필요 — 멈춘다 |
| 계획에 배정·배치·스케줄·경로 로직이 있는데 "모형" 절·"방법 선택" 행이 비어 있음 | 방법 선택(`$optimize`) |
| 계획 승인됨, 기준을 세우는 과제인데 합의문 3-1절 비어 있음 | 2차 왕복 |
| 계획 승인됨, 계획 실행 단계 표에 상태가 대기·진행인 행 | 구현 |
| 변경 있음, `docs/verification.md` 없음 또는 마지막 블록이 현재 변경 이전 | 리뷰·검증 |
| verification PASS, `docs/handoff.md`·`docs/cognition-prep.md` 없음 | 마감 |

   사용자가 `$go T+135 …`처럼 시각을 적으면 decision-log 캘리브레이션 엔트리의 시각 줄(없으면 `docs/playbook.md` 180분 표)도 함께 본다. 완료 기준: "현재 단계: X — 근거: 파일 Y" 한 줄.
2. **요청 해석**: `$go` 뒤 문장을 `AGENTS.md` 9절 표에 대조한다. 둘 이상 맞으면 흐름상 앞선 것. 문장이 없거나 표에 없으면 1단계 결과의 다음 스킬(아래 표).
3. **선언 후 실행**: "→ `$review` 실행(이유: 구현 끝, verification 없음)" 한 줄을 쓰고, `.agents/skills/<이름>/SKILL.md`를 읽어 그 절차를 그대로 따른다. 멈추고 묻는 경우는 셋뿐: 계획 승인 대기, 고위험 변경 진입, 범위 변경.
4. **끝맺음**: 스킬이 끝나면 "다음: `$go` (예상: `$verify`)" 한 줄을 붙인다.

## 단계 → 다음 스킬
| 단계 | 스킬 | 비고 |
|---|---|---|
| 입장 | (스킬 없음) `/status`·`/skills`·spawn 테스트 → 엔트리 1 | |
| 발굴·합의 | `$stakeholder-interview` | 질문은 사용자가 우측 채팅에 직접 |
| 지도·계획 | `$onboard`(기존 코드) → `$plan` | 갈림길·고위험은 `$design-review` |
| 방법 선택 | `$optimize` | 사다리에서 단은 사용자가 고른다. 분석형(통계·이상감지)이면 건너뛴다 |
| 2차 왕복 | `$stakeholder-interview`의 2차 왕복 절 | 2~3안은 `$optimize` 출력에서 |
| 구현 | `$execute` | 깨지면 `$debug`, 모르는 API는 `$research` |
| 리뷰·검증 | `$review` → `$verify` | 고위험은 `$crosscheck` |
| 마감 | `$qa-adversarial`(여유 시) → `$cleanup` → `$verify` 재실행 → `$git-hygiene` → `$handoff` → `$cognition-prep` → `$submission-check` | 15분 미만이면 마지막 둘만 |
| 어디서든 컨텍스트 60% 초과 | `$handoff` → `/new` | |

## 규칙
- 사용자가 `$이름`을 명시하면 이 스킬은 개입하지 않는다.
- 한 번에 스킬 하나. 끝나고 다음.
- Trivial(코드 1파일 자명)은 스킬 없이 AGENTS Trivial 규칙으로 처리하고 그렇게 했다고 말한다.
- 감지가 애매하면 추측하지 말고 "현재 단계 후보: A / B, 어느 쪽?" 한 번만 묻는다.

## 출력
- 현재 단계와 근거 한 줄
- 실행한 스킬과 이유
- 다음에 칠 것
