# remember — 지식 보존

코드나 git 기록으로 알 수 있는 것은 저장하지 않는다. 저장하는 것은 **자명하지 않은 사실, 함정, 선호, 결정 이유**다.

## 저장소 세 곳
| 저장소 | 무엇을 | 수명 |
|---|---|---|
| `docs/notepad.md` | 다음 몇 턴에 필요한 작업 메모(현재 위치, 임시 가설, 보류 항목) | 세션~며칠 |
| `docs/decision-log.md` | 결정·근거·증거·한계(`$evidence-log` 형식) | 영구 |
| `AGENTS.md` 또는 스킬 | 반복해서 적용될 규칙·선호. 두 번 이상 같은 교정을 받았을 때 승격 | 영구 |

## 절차
1. 세션의 발견을 모은다: 사실, 함정, 선호, 폐기된 가정.
2. 항목마다 분류한다: 영구 사실 / 단기 메모 / 규칙 승격 / 중복·낡음·모순.
3. 각 항목을 "무엇 — 왜 — 어떻게 적용"으로 쓴다. 왜가 없으면 규칙은 다음 사람이 지키지 않는다.
4. 알맞은 저장소에만 쓴다. 한 곳에 전부 쏟지 않는다.
5. 기존 항목과 겹치면 새로 만들지 않고 갱신한다. 틀린 것으로 판명된 항목은 지운다.
6. 불확실한 것은 "추정"으로 표시해 저장한다. 사실처럼 쓰지 않는다.

## 규칙
- 비밀값·개인정보는 저장하지 않는다.
- 상대 날짜("어제")는 절대 날짜로 바꿔 적는다.
- 한 항목은 세 줄 안에.

## 출력
- 무엇을 어디에 저장했는지
- 발견한 중복·모순
