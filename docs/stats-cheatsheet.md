# 통계 요약 — 분석형 과제(원인 찾기·그룹 비교·이상 감지)

`docs/domain-fab.md` "최적화가 아닌 유형의 뼈대" 사다리 1단을 채울 때 본다. 도메인 답이 아니라 방법 목록이다. 방법 수준은 사용자가 고른다. 함수 이름은 scipy 기준이며 버전에 없으면 표의 대안을 쓴다.

## 0. 먼저 정할 것
- **분석 단위**: 한 행이 무엇인가(로트·웨이퍼·측정점). 측정점이 여러 개면 단위별 요약값(평균·최댓값·|평균|+3σ·규격 초과 비율)을 먼저 만든다. 측정점을 그대로 표본으로 세면 표본 수가 부풀어 p값이 거짓으로 작아진다.
- **지표 형태**: 연속(크기) / 이진(규격 초과 여부). 가능하면 둘 다 본다.
- **요인**: 무엇으로 그룹을 나누나(단계×장비, 챔버, 조합, 기간). 요인마다 그룹별 표본 수를 먼저 센다.
- **최소 표본**: 그룹 n < 5면 검정하지 않고 "판단 불가(표본 부족)"로 표시한다.

## 1. 검정 고르기
| 지표 | 그룹 수 | 기본(분포 가정 없음) | 대안(정규에 가까울 때) |
|---|---|---|---|
| 연속 | 2 | Mann-Whitney U `mannwhitneyu` | Welch t `ttest_ind(equal_var=False)` |
| 연속 | 3 이상 | Kruskal-Wallis `kruskal` | 일원 분산분석 `f_oneway` |
| 이진 | 2 (2×2 표) | Fisher 정확 검정 `fisher_exact` | — |
| 이진 | 3 이상 | 카이제곱 `chi2_contingency`(기대빈도 5 미만 칸이 많으면 그룹을 "해당 그룹 대 나머지"로 묶어 Fisher) | — |
| 산포(흩어짐) 비교 | 2 이상 | Levene `levene(center='median')` | — |
| 시간에 따른 추세 | — | Spearman 순위상관 `spearmanr`(시각 대 지표) | 전후 구간 비교는 2그룹 검정 |

요인이 많으면 "그룹 A 대 나머지 전체" 2그룹 비교로 통일하면 순위 매기기가 쉽다. 장비 수가 많은 단계에서 전체 검정(3 이상)만 하면 어느 그룹이 문제인지 모른다.

## 2. 효과 크기 — p값만으로 순위를 매기지 않는다
p값은 표본이 크면 사소한 차이도 작아진다. 화면에는 **단위가 있는 차이**를 먼저 보인다.
| 상황 | 효과 크기 | 읽는 법 |
|---|---|---|
| 연속, 2그룹 | 중앙값 차이(원래 단위), Cliff's delta = 2·U/(n1·n2) − 1 | delta 절댓값 0.33 이상 중간, 0.47 이상 큼(관례) |
| 연속, k그룹 | ε² = H / (n − 1) (H는 Kruskal-Wallis 통계량) | 0~1, 요인이 설명하는 비율의 근사 |
| 이진 | 불량률 차이(%p), 위험비 = 그룹 불량률 ÷ 나머지 불량률, 오즈비 | 위험비 2면 두 배 |
| 신뢰구간 | 부트스트랩 `bootstrap` 또는 직접 재표집 1000회, 시드 고정 | 구간이 0(또는 비 1)을 포함하면 불확실 |

## 3. 다중 비교 보정 — 요인·그룹이 많으면 반드시
검정을 m번 하면 우연히 유의한 것이 약 m×0.05개 나온다.
- **Bonferroni**: p × m. 보수적, 설명이 쉽다.
- **Benjamini-Hochberg(FDR)**: 기본 권장. "유의하다고 한 것 중 거짓 비율"을 q(보통 0.05~0.1) 이하로. `scipy.stats.false_discovery_control`(scipy 1.11 이상)이 없으면 아래 6줄.

```python
import numpy as np
def bh_adjust(p):
    p = np.asarray(p, float); m = len(p); order = np.argsort(p)
    adj = p[order] * m / np.arange(1, m + 1)
    adj = np.minimum.accumulate(adj[::-1])[::-1]
    out = np.empty(m); out[order] = np.minimum(adj, 1.0); return out
```

- **순열 검정(최대 통계량)**: 가정이 가장 적다. 지표 값을 무작위로 섞어 전체 분석을 다시 돌리고, 매번 "가장 큰 효과"를 기록한다(500~1000회, 시드 고정). 실제 1위 효과가 그 분포의 상위 5% 안이면 우연이 아니다. "우연히 이 정도 1위가 나올 확률"을 화면에 한 줄로 보일 수 있다.

## 4. 교란 — 가장 많이 틀리는 곳
- **경로 겹침**: 두 요인이 거의 항상 같이 나타나면(장비 A를 거친 것이 대부분 장비 B도 거침) 둘을 구별할 수 없다. 요인 쌍의 동시 출현 표를 만들고, 겹침이 크면 "구별 불가, 함께 의심"으로 묶어 보고한다.
- **층화**: 다른 요인을 고정한 안에서 다시 비교한다(제품별·기간별·이전 단계 장비별). 층마다 방향이 같으면 신뢰가 오른다. 2×2 표의 층화 통합은 Cochran-Mantel-Haenszel.
- **심슨의 역설**: 전체에선 A가 나빠 보이는데 층별로는 모두 정상일 수 있다(A가 어려운 제품을 더 많이 처리). 층별 표를 같이 보인다.
- **시간**: 불량이 특정 기간에 몰려 있으면 그 기간에 많이 쓰인 요인이 전부 의심받는다. 기간을 나눠 요인 효과가 기간 안에서도 남는지 본다. 정비·교체 시점 전후 비교는 강한 증거다.
- **반대 증거**: "의심 요인을 거쳤는데 정상"인 건수와 "거치지 않았는데 불량"인 건수를 항상 같이 적는다.

## 5. 관리도·이상 감지(시간 순 데이터)
- 개별값 관리도: 중심선 = 평균, 한계 = 평균 ± 3σ. σ는 이동범위 평균 ÷ 1.128로 추정한다(전체 표준편차는 드리프트에 부풀려진다).
- 견고한 대안: 중앙값 ± 3 × 1.4826 × MAD. 이상치가 섞인 기준 구간에 쓴다.
- 추가 규칙(관례): 한쪽으로 연속 8점, 3점 중 2점이 2σ 밖. 규칙을 늘릴수록 오경보가 는다 — 하루 오경보 건수를 같이 센다.
- 작은 드리프트: EWMA z_t = λ·x_t + (1−λ)·z_{t−1}, λ 0.1~0.3.
- 공정능력: Cpk = min(USL − μ, μ − LSL) ÷ 3σ. 1.33 이상을 흔히 양호로 본다(기준은 실무자에게 확인).
- 기준 구간(한계를 계산한 구간)과 감시 구간을 분리한다. 같은 구간으로 한계를 만들고 판정하면 검출률이 과장된다.

## 6. 순위 점수와 화면에 낼 숫자
- 순위는 **효과 크기 우선, 보정 p값은 문턱**으로: 보정 p ≤ q이고 표본이 충분한 후보만 효과 크기 순으로 세운다. 가중합 점수를 쓰면 가중치를 파라미터로 빼고 출처를 적는다.
- 후보마다: 표본 수(그룹/나머지), 중앙값 또는 불량률(그룹/나머지), 차이와 신뢰구간, 보정 p, 반대 증거 건수, 겹치는 다른 요인, 기간별 일관성.
- 문구: "원인이다"가 아니라 "가장 강하게 연관된 후보이며 확인이 필요하다". 상관이지 인과 확정이 아니다.

## 7. 검증 계획(`$verify`에 넘김)
1. **심은 원인 찾기**: 합성 또는 실제 데이터에 알려진 크기의 효과를 한 요인에 더하고 1위로 나오는지. 효과를 줄여 가며 찾지 못하는 크기를 적는다(검출 한계).
2. **무효 확인**: 지표를 섞은 데이터에서 유의 후보가 q 비율 이하로 나오는지.
3. **독립 재계산**: 1위 후보의 표본 수·중앙값·불량률을 다른 코드(직접 필터·집계)로 다시 계산해 일치하는지.
4. **재현성**: 같은 입력·같은 시드에서 같은 순위. 표본 일부(예: 80%)만 써도 상위 후보가 유지되는지.
5. **경계**: 그룹 1개뿐인 요인, 전부 정상·전부 불량, 결측이 많은 열에서 오류 없이 "판단 불가"로 표시되는지.

## 8. 확인 문제 답 틀
"<단위>를 <요인>별로 나눠 <검정>으로 비교했고, 요인이 N개라 <보정>을 했다. 1위는 차이 <단위 있는 숫자>, 보정 p <값>, 우연히 이 정도가 나올 확률 <순열 결과>다. 약점은 <경로 겹침·표본 부족·기간 편중>, 파급은 <잘못 지목했을 때 생기는 일>, 다음 검증은 <층화·새 기간 데이터·현장 확인>."
