# 반도체 현장 과제 — 어휘와 유형 지도 (결선 대비, 1쪽)

목적: 인터뷰 질문이 현장 말로 나오게, 과제를 받자마자 문제군을 맞히게. **답을 미리 만들지 않는다.** 과제가 FAB 밖(사무·물류·안전·HR)일 수도 있으니 어휘는 참고, 유형 표는 공통이다.

## 어휘 — 실무자 말 → 뜻 → 어디에 쓰나
| 말 | 뜻 | 쓰는 곳 |
|---|---|---|
| 로트(lot)·웨이퍼 | 처리 단위(로트 = 웨이퍼 묶음, 보통 25장) | 디스패칭의 결정변수 |
| 공정 스텝·레시피·re-entrant | 로트가 거치는 수백 스텝, 같은 설비군을 여러 번 재방문 | 스케줄 제약 |
| 설비군(tool group)·챔버 | 같은 공정을 하는 설비 묶음 | 배정 대상 |
| 병목(bottleneck) | 가동률이 가장 높은 설비군(포토 등) | 목적함수 후보 |
| WIP·사이클타임·TAT | 재공 수, 투입→완료 시간 | 성공 기준 숫자 |
| 처리량·가동률·OEE | 산출/시간, 가동 비율 | 성공 기준 숫자 |
| PM(예방정비)·다운타임 | 계획 정지·고장 | 스케줄 제약 또는 목적 |
| 배치(batch) 공정·셋업 | 여러 로트 동시 처리(확산로 등), 종류 전환 비용 | 묶기·순서 제약 |
| 수율(yield)·불량(defect)·SPC | 양품 비율, 관리도 | 분석형 과제 |
| 디스패칭 규칙 | FIFO·EDD(납기)·CR(critical ratio)·SPT | `$optimize` 사다리 0·1단 |
| AMHS·OHT·스토커 | 자동 반송(천장 반송차), 보관 장치 | 경로·배치 과제 |
| 클린룸 등급·베이(bay) | 구역 단위 | 배치 과제의 공간 제약 |

## 유형 → 문제군 → 뼈대 (`$optimize`)
| 현장 고민 | 교과서 문제군 | 결정변수 | 전형적 제약 |
|---|---|---|---|
| 어느 로트를 어느 설비에, 어떤 순서로 | 잡숍 스케줄링·배정 | 로트→설비, 시작 시각 | 설비 용량, 셋업, 납기, PM 창 |
| 센서·카메라·AP를 어디에 몇 대 | 예산 제약 최대 커버 / 집합 커버 / 시설 입지 | 후보 위치×종류×방향 | 예산, 필수 지점, 시야·거리, 차폐 |
| PM을 언제 | 구간 스케줄링 MILP | 설비×시간창 | 동시 정지 상한, 생산 계획 |
| 반송·동선·셔틀 | VRP·최단 경로 | 경로·배차 | 용량, 시간창 |
| 어떤 로트를 묶어 넣나 | 빈 패킹·배치 구성 | 로트→배치 | 용량, 레시피 호환 |
| 급식·자재 배합·예산 배분(공장 밖 운영 과제) | 배합(diet/blending) LP·MILP | 품목×수량(일자별) | 영양·성분 범위, 예산, 다양성·반복 상한, 재고 |
| 수율이 왜 떨어졌나, 설비가 이상하다 | **분석형**(가설검정·트리 모델·시계열 롤링 통계) | — | `$optimize` 대상 아님. 기준선 통계부터 |

## 인터뷰에서 바로 쓰는 질문 어휘
"지금은 이 결정을 누가 어떤 기준으로 하나요", "병목이 어디라고 보시나요", "하루 몇 로트(건)인가요", "예산·대수·시간 상한은요", "꼭 지켜야 하는 곳(필수)과 절대 안 되는 곳(금지)은요", "지금 방식의 결과를 숫자로 알 수 있나요(현재값)". 반대 당사자(비용·안전·품질 부서)의 임계값을 숫자로 받는다.

## 주의
- 도메인 세부 해법을 미리 만들지 않는다(미리 만든 답처럼 보인다). 이 문서는 어휘와 분류만.
- 실전에서 본 과제들(경로 구성, 장비 배치·선택, 배합·구성)의 공통 형태는 "예산 제약 최적화 + 기준 직접 수립 + 실무자 webUI + Docker"였고 **도메인은 매번 달랐다**(공장 안팎 모두). 결선도 뼈대는 같을 가능성이 크지만 소재는 열어 둔다.
